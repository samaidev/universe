## 闭环推导

```
c* = Δx / Δt                          (因果上限，非自由参数)
h* = ρ · (Δx)³ / Δt = ρ · c* · (Δx)²  (等效普朗克常数)
l_P = √(h·G/c³)                       (普朗克尺度涌现)
```

归一化 ρ=1，Δx=Δt=1 时：c*=1, h*=1, l*_P=1。
